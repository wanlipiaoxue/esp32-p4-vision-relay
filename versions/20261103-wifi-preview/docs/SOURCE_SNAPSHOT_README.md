## 候选行为

保留原 640×480 YUY2、10帧采集；AprilTag L1/L2、确认门槛、灯带锁存清除、GPIO映射、语音和UART主逻辑未修改。主源码仅增加预览模块 include、一次非阻塞旁路交帧和模块启动三处。

新增 320×240 灰度JPEG预览。图传使用私有缓冲，在Core0低优先级任务编码与服务；USB取帧不等待HTTP发送。没有手机取图时停止旁路编码，缓冲忙或画面过期时丢弃预览帧。已关闭ESP-Hosted传输故障自动重启P4，故障事件只暂停预览。固定版本Hosted库原先通过构造函数在app_main前初始化；候选构建排除该自动初始化文件，改在原识别与USB初始化完成后的网络任务中显式调用，不改动managed组件文件。

这些是源码设计与静态差异核对结果，不代表已证明图传不影响识别。当前预览受原采集限制，最多约10个新帧/秒，未实现24帧目标。实际帧率与延迟待用户测试。

## 烧入后手机的拟定连接方法

1. USB识别摄像头接到P4，板卡正常供电。
2. NX729J连接热点 RM-P4-Camera，密码 CHANGE_ME_12345。
3. 如果系统提示没有互联网，选择保持连接。
4. 用Chrome或Edge打开 http://192.168.4.1/ ，在前台观看。
5. 暂停画面按钮只停止手机取图，不发送识别暂停或灯带命令。

页面按序号读取最新JPEG，一次一个图像请求，250毫秒请求超时，超过350毫秒没有新图则标记画面过期。设备侧帧龄加请求耗时的显示值不是完整拍摄到屏幕延迟。锁屏或浏览器进入后台不作为持续播放方案。

热点、网页和C6出厂固件配套关系尚未在板上验证，不能据配置字符串宣称热点已经可用。C6本轮没有刷写。
