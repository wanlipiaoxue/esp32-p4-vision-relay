# RM P4 viewer design

Operate surface. The single question is whether the claw is holding the object in the current frame.

The committed direction is true-black-flat from design-taste-frontend. Keep the camera canvas dominant, one compact top bar and plain readings below it. Ground #000, camera backing #111, secondary buttons #2a2a2a, foreground #f2f2f2. Only live-state text uses a restrained green. Buttons remain neutral; the full-screen control is white with dark text.

Use local system CJK fonts and touch controls at least 44px tall. A stale image is visibly dimmed and labelled; loading, paused, live and disconnected states use literal Chinese labels. No visual validation was performed, per user instruction.
